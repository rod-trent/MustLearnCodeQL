# Chapter 13 Exercises

1. Rewrite a query that uses a broad `exists` so that it uses a more direct predicate instead.
2. Take a path query that returns no results and insert an intermediate local-flow check to find where the flow stops.
3. Compare the runtime of two versions of the same query (with and without an extracted predicate) on a moderately large database.
4. (Optional) Use the CodeQL profiler or timing output to identify the slowest predicate in one of your queries.
