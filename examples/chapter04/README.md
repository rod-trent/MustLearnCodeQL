# Chapter 4 Examples

Minimal QL examples referenced in Chapter 4 of *Must Learn CodeQL*.

## small-int-triples.ql

Demonstrates classes, member predicates, and a simple query.  
Run against any CodeQL database (the query does not depend on language-specific libraries):

```bash
codeql query run --database=my-first-db small-int-triples.ql
```

See the book chapter for the surrounding explanation of predicates, classes, recursion, and aggregates.
