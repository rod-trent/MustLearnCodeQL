# Chapter 10 Examples

Example queries and models referenced in Chapter 10 of *Must Learn CodeQL*.

## Files

- `custom-source.ql` — demonstrates a custom source.
- `custom-sink.ql` — demonstrates a custom sink.
- `flow-summary-example.ql` — skeleton showing a simple flow summary style model.
- `README.md` — this file.

## Running

These are illustrative. In practice you place models in a library pack and import them. Create a database first (see Chapters 2–3), then explore in the CodeQL extension for VS Code.

See the book chapter for guidance on extending the standard libraries with custom sources, sinks, and models.
