# Swift Standard Library — Key Classes

Import with:

```ql
import swift
```

## Core classes

| Class | Description |
|-------|-------------|
| `File` | Source file |
| `Function` | Function |
| `Class` | Class |
| `Expr` | Expression |
| `Stmt` | Statement |
| `CallExpr` | Call |

## Useful predicates (examples)

- `Function.getName()`
- `Function.getACall()`

For full details see the official [CodeQL standard library for Swift](https://codeql.github.com/codeql-standard-libraries/swift/).
