# Lexical Syntax

QL lexical elements include keywords, identifiers, literals, and comments.

## Keywords

Common keywords: `class`, `predicate`, `module`, `import`, `select`, `from`, `where`, `extends`, `implements`, `exists`, `forall`, `if`, `then`, `else`, `and`, `or`, `not`, `in`, `instanceof`.

## Identifiers

- Start with a letter or underscore
- May contain letters, digits, and underscores

## Literals

| Kind | Examples |
|------|----------|
| Integer | `42`, `0xFF` |
| Float | `3.14` |
| String | `"hello"` |
| Boolean | `true`, `false` |

## Comments

```ql
// line comment
/* block comment */
```

## Notes

- QL is case-sensitive.
- See also the official lexical syntax documentation.
